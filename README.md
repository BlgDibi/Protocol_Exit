# Protocol: Exit

Külső nézetes (Third-Person) 3D-s logikai kalandjáték Unity környezetben (szakdolgozati projekt).

## Gyors indítás (kész build)
A játék telepítés nélkül kipróbálható a jobb oldali **Releases** szekcióból letölthető `.zip` állomány kicsomagolása után a `ProtocolExit.exe` elindításával (Windows 10/11 64-bit).
